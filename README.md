MS Leveling 2.01b Addon for Manastorm — Usage Guide

Auto buttons
Post LFM — posts group counts to configured channels.
AutoLFM — reposts every 30s.
Auto-LFG — auto-invites LFG messages for MS/Manastorm from selected channels.
AutoReply — auto whisper replies (confirm/reject/help).
All three turn themselves off at 15/15. The numbered buttons (1–3, 0 = none) pick the channels.
Building the raid

Load Raid — wipes lists, asks the raid to reply 1=Tank, 2=Heal, 3=Aura (e.g. 1 3); no reply = DPS no aura.
Members reply in raid chat or whisper.
Finish Count — collects the roster with roles and announces the summary.
Raid tools

Sort Groups — spreads tanks/heals/auras across subgroups, marks MTs, announces per-group; auto-runs after combat if needed. MT buttons run /maintank <name>.
Update raid — syncs the invited list with the real roster.
Ready Check — runs a ready check.
Enter MS 1 — clicks Ascension's Manastorm enter button (multiple fallbacks; set a custom button with /mslv enter <name>).
Disband+Re-inv — disbands saving roles/auras, waits until you leave the dungeon, then re-invites everyone (invites 4 → converts to raid → invites the rest).
Anti-leech (default on; toggle via the Anti-leech button)

Flags AFK/Idle 45s+, and leechers after 2 idle loads with no damage/healing.
Warns in raid chat at level 59 and auto-kicks at level 60.
All flagged players appear in the Warnings panel with per-row Kick (/mslv warnings, /msw).
Slash commands

/mslv — toggle panel
/msw — Warnings panel
